# Vidéo Hero

Place ta vidéo ici : `hero.mp4`

Specs recommandées :
- Format : MP4 (H.264)
- Résolution : 1920x1080
- Durée : ~15 secondes (en boucle)
- Poids : ≤ 5 Mo (compresse avec HandBrake)

Sans vidéo, le hero utilise automatiquement :
1. Une image de fallback (dunes Marrakech)
2. Une vidéo CDN de secours (Pexels)
